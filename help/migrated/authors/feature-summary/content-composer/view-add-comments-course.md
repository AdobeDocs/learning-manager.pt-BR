# Exibir e adicionar comentários a um curso

Se você criou o curso, selecione o painel **Comentários** em seu projeto para ver os comentários e respondê-los.

1. **Abra o painel Comentários**: selecione **Comentários** na barra de ferramentas. O painel de comentários exibe os comentários fornecidos pelo revisor.

2. Você pode marcar os comentários como resolvidos ou editar ou excluir os comentários.

3. Faça as alterações necessárias e **Salve** o projeto.

4. Selecione **Compartilhar** na barra de ferramentas para atualizar o link mais recente.
