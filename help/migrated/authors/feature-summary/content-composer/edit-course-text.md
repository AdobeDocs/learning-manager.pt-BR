# Editar o texto do curso

    ![](../assets/15_lesson_image_text_block_fall_prevention_updated.png)

Selecione qualquer elemento de texto para colocar o cursor dentro dele. Uma barra de ferramentas de formatação aparece na parte inferior da tela com os controles negrito, itálico, sublinhado, tachado, vínculo, alinhamento e lista.

>[!NOTE]
>
>Os nomes de tópicos e de lição fazem parte da estrutura de tópicos. Para renomeá-los depois que o curso for gerado, pergunte ao assistente: “Renomeie a lição 2 para “Higiene da senha”.” Não é possível renomeá-los selecionando um cabeçalho no editor de cursos.
