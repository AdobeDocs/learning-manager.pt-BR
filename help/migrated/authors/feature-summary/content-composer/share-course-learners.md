# Compartilhar um curso com os alunos

1. Selecione **Para alunos**.

2. Selecione **Gerar link** para gerar um link para o aluno acessar o projeto.

3. Compartilhe o link com seus alunos.

>[!IMPORTANT]
>
>Sempre que você atualiza o curso, os alunos podem usar o mesmo link para ver as alterações do curso.
