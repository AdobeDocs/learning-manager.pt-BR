# Aplicar um tema

Os temas do curso controlam fontes, cores, cabeçalhos, rodapés e o estilo dos componentes em todo o curso.

Aplique um tema ao seu curso sem nenhuma personalização para obter uma aparência rápida, elegante e consistente.

1. Selecione **Temas** na barra de ferramentas. O painel **Temas do curso** é aberto, mostrando todos os temas disponíveis.
   ![](../assets/34_course_themes_panel_open_updated.png)

2. Navegue pelos temas disponíveis:

   1. **Padrão:** exibe os temas internos que vêm com o Compositor de Conteúdo.

   2. **Personalizado:** exibe os temas que você criou e salvou.

   3. Use a barra **Pesquisar** para localizar um tema por nome.

3. Selecione um tema para aplicá-lo. A visualização do curso é atualizada automaticamente.
