# Definir configurações do quiz

Selecione **Quiz** para configurar como o quiz se comporta e como ele é pontuado.

Esta guia tem duas seções: **Geral** e **Pontuação**.

![](../assets/27_quiz_settings_general_scoring_scorm12_updated.png)

## Seção Geral

- **Tentativas do quiz**: escolha o número de tentativas que um aluno obtém para concluir o quiz. Por exemplo, selecione **3** para permitir até 3 tentativas.
  ![](../assets/28_quiz_retries_dropdown_options_updated.png)

- **Limite de tempo (minutos)**: selecione a opção para habilitar um limite de tempo e insira a duração em minutos. Por exemplo, insira **60** para conceder aos alunos 60 minutos para concluir o quiz.

- **Ordem de perguntas aleatória**: selecione a opção para mostrar as perguntas em uma ordem aleatória para cada aluno.
  ![](../assets/29_quiz_randomize_question_order_toggle_updated.png)

- **Embaralhar opções de resposta:** selecione a opção para embaralhar as opções de resposta para cada pergunta.
  ![](../assets/30_quiz_shuffle_answer_choices_toggle_updated.png)

## Seção Pontuação

- **Padrão**:

Selecione a versão do SCORM usada para relatar os resultados do quiz ao LMS. Escolha a versão que corresponde aos requisitos de compatibilidade do LMS.
Por exemplo, selecione **SCORM 1.2**.

>[!NOTE]
>
>Se não souber qual versão do SCORM escolher, consulte o administrador do LMS.
