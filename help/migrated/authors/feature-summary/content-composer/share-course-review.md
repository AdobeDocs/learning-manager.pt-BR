# Compartilhar um curso para revisão

1. Selecione **Para revisão**.

2. Insira os nomes ou endereços de email dos revisores no campo Adicionar nomes ou emails.

3. Revise a seção **Quem tem acesso** para confirmar se apenas as pessoas convidadas podem acessar o projeto.

4. Selecione **Convidar para comentar** ou **Copiar link** para compartilhá-lo com seus revisores.
