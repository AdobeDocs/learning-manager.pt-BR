# Configurações gerais do curso

1. Abra seu curso.

2. Selecione **Configurações** para abrir **Configurações do curso**.
   ![](../assets/20_course_settings_general_tab_scorm12_updated.png)

3. Selecione **Geral** para configurar os critérios de **conclusão** e **sucesso**:

Os critérios de conclusão determinam quando um curso é marcado como concluído no LMS, com base no progresso do aluno, não no desempenho.
