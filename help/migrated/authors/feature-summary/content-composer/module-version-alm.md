# Controle de versão do módulo no Adobe Learning Manager

O material de origem muda com o tempo - uma política é revisada, um SOP recebe uma nova versão e um conjunto de instruções é atualizado. O Compositor de conteúdo e o ALM lidam com uma atualização como uma alteração de versão, não uma edição no local, portanto os cursos publicados anteriormente continuam funcionando enquanto você atualiza o módulo subjacente.

Ao republicar, o Adobe Learning Manager faz upload do módulo existente como uma nova versão na Biblioteca de conteúdo, incrementando o número de versão do módulo em um.

1. No Compositor de conteúdo, atualize os arquivos de origem e gere novamente as lições afetadas (consulte Atualizar um curso quando o material de origem mudar), em seguida, republique.

2. A publicação da atualização não substitui o módulo existente, pois adiciona uma nova versão junto com ele na Biblioteca de Conteúdo do ALM.

3. Um autor do ALM precisa atualizar explicitamente cada curso do ALM que usa o módulo para apontar para a nova versão; os cursos existentes continuam fazendo referência à versão com a qual foram criados até que um autor do ALM faça essa alteração.

4. Os alunos que já concluíram o curso na versão anterior mantêm o registro de conclusão existente. A nova versão se aplica aos alunos inscritos depois que o curso ALM é atualizado.

Revise as lições regeneradas no Compositor de conteúdo antes de republicar. A regeneração pode ajustar perguntas, imagens ou textos editados anteriormente nas lições afetadas.
