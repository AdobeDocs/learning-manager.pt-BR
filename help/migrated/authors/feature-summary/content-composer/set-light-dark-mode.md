# Definir o modo claro ou escuro do curso

<!--Select **light/dark** mode in the toolbar to toggle between modes. Content Composer updates the canvas to reflect the selected mode.-->

Selecione [!UICONTROL Menu Conta] > [!UICONTROL Aplicar tema] > modo claro ou escuro. O Compositor de conteúdo atualiza a tela para refletir o modo selecionado.
