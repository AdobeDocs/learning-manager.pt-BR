# Editar a estrutura do curso

![](../assets/10_outline_tab_generated_lessons_topics_updated.png)

O Adobe Learning Manager Content Composer gera uma estrutura de tópicos e lições a partir do resumo e do arquivo de origem. O contorno aparece na tela mostrando todas as lições e seus tópicos.

**Observação:** a edição da estrutura de tópicos está em conversação na versão beta. Não é possível selecionar uma lição ou tópico na tela para renomeá-lo ou reordená-lo. Digite sua alteração como uma solicitação em linguagem simples no painel de bate-papo.

O assistente trabalha conversacionalmente. Você pode formular pedidos de frases com suas próprias palavras. Veja alguns exemplos do que você pode fazer:

| **Ação** | **Exemplo de solicitação** |
|--------------------------|---------------------------------------------------------------------------|
| Renomear uma lição ou tópico | “Renomear a Lição 1 para &#39;Como o Phishing Funciona&#39;” |
| Adicionar uma lição ou tópico | “Adicionar um tópico à Lição 2 sobre o phishing de código QR” |
| Excluir uma lição ou tópico | “Remover tópico 1.3” |
| Dividir uma lição | “Divida a lição 3 em duas. Um para filtros de spam, outro para gerenciamento de patches” |
| Mesclar lições | “Combinar as lições 3 e 4 em uma lição” |
| Regenerar a estrutura de tópicos | “Regenerar com mais foco na higiene de senhas” |

Use solicitações em linguagem simples no painel de bate-papo para modificar lições, tópicos ou a estrutura completa de tópicos.

A hierarquia da estrutura de tópicos é definida como Lições > Tópicos. Não é possível criar subtópicos ou estruturas de três níveis.

Quando a estrutura de tópicos parecer correta, selecione **Gerar curso** na barra de ferramentas superior.
