# Criar uma interpretação usando um modelo de Treinador virtual

O Publish apresenta um cenário de Virtual Coach pré-criado em minutos, começando a partir de um modelo em vez de criar um role-play do zero.

As seções **Modelos em destaque** e **Modelos disponíveis** do Virtual Coach contêm uma biblioteca de cenários de reprodução de função pré-criados, que abrangem situações de vendas, liderança e avaliação de habilidades. Usar um modelo é a maneira mais rápida de criar uma interpretação de papéis — a persona, a abertura da conversa, os tópicos e a pontuação já estão configurados e você pode publicar imediatamente ou personalizar qualquer detalhe antes de publicar.

Os modelos são organizados por domínio, tipo de simulação e idioma. Use os filtros para restringir a lista por tipo de interação, como **Conversas por Voz** ou **Prática com Webcam**, ou pesquise por palavra-chave para encontrar um cenário mais próximo de seu caso de uso.

>[!TIP]
>
>Selecionar um modelo não bloqueia você em sua configuração padrão. Todos os campos, incluindo o plano de fundo pessoal, tópicos, pesos de pontuação e abertura da conversa, podem ser editados após a seleção do modelo. Trate os modelos como um ponto de partida, não como um design final. Para obter uma explicação completa de cada campo configurável, consulte [criar e publicar uma função de treinador virtual](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md).


1. Faça logon no Adobe Learning Manager como autor.
2. Selecione **Virtual Coach** no painel de navegação à esquerda.
3. Selecione **Criar agora**.
4. Navegue pela seção **Modelos Disponíveis** ou use a barra **Pesquisar** e os filtros de domínio, tipo de simulação e idioma para encontrar um modelo que corresponda ao seu cenário.

   ![](/help/migrated/authors/feature-summary/assets/virtual-coach25.png)
5. Selecione o bloco de modelo para abri-lo. Revise a configuração pessoal, de tópicos e de pontuação.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach17.png)
   *Revise o contexto de conversa pré-preenchido e o plano de fundo pessoal antes de decidir se deseja personalizar o modelo.*

6. Para usar o modelo como ele está, selecione **Publish**. Para personalizá-la primeiro, selecione qualquer seção e edite os campos relevantes antes de publicar.

Depois de publicada, a representação é adicionada à **Biblioteca de Conteúdo** e está pronta para ser adicionada a uma ajuda de tarefa e atribuída a um curso. Consulte [adicionar uma interpretação de função de treinador virtual a um curso](/help/migrated/authors/feature-summary/virtual-coach/add-virtual-coach-role-play-to-course.md) para essas etapas ou [praticar uma interpretação de função com o treinador virtual](/help/migrated/learners/feature-summary/virtual-coach/practice-role-play-with-virtual-coach.md) para ver a experiência do aluno.
