# Ativar o Live Hub no Adobe Learning Manager

Os administradores podem habilitar o Live Hub para uma conta do Adobe Learning Manager e configurar assistentes viabilizados por IA para oferecer suporte aos professores durante as sessões ao vivo. Depois que o Live Hub é habilitado, os autores podem usar as ferramentas de treinamento virtual do Live Hub para criar e gerenciar módulos de Sala de aula virtual para cursos.

Para ativar o Live Hub:

1. Faça logon no Adobe Learning Manager como administrador.

1. Selecione **IA em Aprendizado** no painel de navegação esquerdo.

   ![IA No Learning Nav](assets/ai-in-learning-nav.png)
   *Selecione IA em Aprendizado para habilitar o Live Hub.*

1. Selecione o **Live Hub**. <br> A página **Live Hub** é aberta.

   Página de Configurações do Hub do ![Live](assets/live-hub-settings-page.png)
   *As configurações do Live Hub mostram a opção de habilitar o Live Hub no ALM.*

1. Ative o **Habilitar o Live Hub para esta conta**. <br> A caixa de diálogo **Definir o Live Hub como padrão** é exibida.

   ![Definir Caixa de Diálogo Padrão do Live Hub](assets/set-live-hub-default-dialog.png)
   *Selecione Definir como padrão na janela pop-up.*

1. Escolha uma das seguintes opções:

   1. **Definir como padrão**: torna o Live Hub o provedor de sala de aula virtual padrão. O Live Hub é pré-selecionado quando os autores criam um módulo de sala de aula virtual para um curso.

   1. **Não agora**: fecha a caixa de diálogo sem alterar o provedor de sala de aula virtual padrão. Você pode habilitar essa configuração mais tarde na página do Live Hub.

1. Ative o **AI no Hub do Live** para disponibilizar assistentes com IA em sessões ao vivo.

   ![Habilitar Ia No Live Hub](assets/enable-ai-in-live-hub.png)
   *Habilite a IA no Live Hub para habilitar os agentes do Live Hub.*

1. Habilite os assistentes dos agentes do Live Hub:

   1. Assistente de enquetes

   1. Assistente de perguntas e respostas

   1. Assistente de monitoramento de grupos de discussão

   1. Gerador de tópicos para gravações

   1. Assistente de busca para professores

>[!NOTE]
>
> Os assistentes de IA podem ser configurados somente quando a IA no Live Hub estiver ativada. Os professores podem desativar os assistentes ao preparar uma sessão, mas não podem ativar um assistente que foi desativado por um administrador.

Exiba [Introdução ao Live Hub](../../getting-started-with-live-hub/getting-started-live-hub.md) para obter mais informações.
