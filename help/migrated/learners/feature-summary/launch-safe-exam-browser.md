# Iniciar um quiz no Navegador de exame seguro

O navegador Safe Exam Browser (SEB) é um navegador seguro projetado para fornecer um ambiente controlado para avaliações on-line. O Adobe Learning Manager é compatível com o Navegador de exames seguros para questionários que exigem um ambiente de teste seguro. Quando você seleciona um quiz que requer o Navegador de exame seguro, o Adobe Learning Manager solicita que você baixe ou inicie o Navegador de exame seguro antes de poder acessar a avaliação.

O Navegador do exame seguro fornece um ambiente restrito para fazer o quiz. Depois que o navegador Safe Exam é iniciado, o acesso a outros navegadores e aplicativos é restrito e as chamadas ativas são desconectadas.

O Navegador do exame seguro é necessário apenas para o questionário selecionado e não afeta outros módulos do curso, como sessões de sala de aula virtual.

Este artigo explica como baixar o navegador Safe Exam, iniciá-lo no Adobe Learning Manager e acessar o quiz.

**Baixar Navegador de Exame Seguro**

Se o navegador Safe Exam não estiver instalado no seu dispositivo, siga estas etapas para baixá-lo e instalá-lo:

1. Abra o curso e selecione o questionário em ritmo individualizado que requer o Navegador de exame seguro.
1. Selecione **Baixar SEB**. A página de download do Navegador do Safe Exam é aberta.

   ![Prompt informando que a avaliação é aberta somente no Navegador de Exame Seguro, com os botões Baixar SEB e Iniciar SEB](assets/download-or-launch-seb-prompt.png "Prompt informando que a avaliação é aberta somente no Navegador de Exame Seguro, com os botões Baixar SEB e Iniciar SEB")

1. Baixe e instale a versão apropriada do navegador Safe Exam para o seu dispositivo.
1. Após a conclusão da instalação, volte ao questionário no Adobe Learning Manager.

## Iniciar Navegador de Exame Seguro

Após instalar o Navegador Safe Exam, inicie o aplicativo para acessar o quiz.

1. Abra o curso e selecione o questionário em ritmo individualizado que requer o Navegador de exame seguro.
1. Selecione **Iniciar SEB**.
1. Permita as permissões de sistema necessárias quando solicitado.
O Navegador do Safe Exam é iniciado e abre o quiz selecionado.
1. Acesse o quiz e conclua a avaliação no Navegador de exame seguro.
   >[!NOTE]
   >
   > Ao fazer logon no Adobe Learning Manager por meio do Navegador de exame seguro (SEB), você pode acessar apenas os questionários atribuídos e não tentados que exigem o SEB. Não é possível acessar outros conteúdos de aprendizado.
1. Selecione **Sair do SEB**.
Você é redirecionado para a página configurada para sua conta.
