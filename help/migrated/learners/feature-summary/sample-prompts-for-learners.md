# Exemplos de prompts para alunos do Adobe Learning Manager

Você precisa conectar seu cliente de IA primeiro. Exibir [Conectar seu cliente de IA](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md). Cada prompt mapeia para uma ferramenta na [referência das ferramentas do aluno.](/help/migrated/learners/feature-summary/learner-tools-reference.md)

## Inscrições

| **Aviso** | **Ferramenta** |
|------------------------------------------|----------------|
| Em quais cursos estou inscrito? | Obter inscrição |
| Quais dos meus cursos estão prestes a expirar? | Obter inscrição |

## Pesquisa

| **Aviso** | **Ferramenta** |
|-----------------------------------------|----------|
| Quais cursos de liderança estão disponíveis? | Pesquisa |
| Mostrar o treinamento de segurança disponível para mim. | Pesquisa |

## Conhecimento

| **Aviso** | **Ferramenta** |
|---------------------------------------------------------|--------------|
| O que significa o gerenciamento de riscos da cadeia de fornecimento no FedRAMP? | Agente de resposta |
| Explicar os requisitos no meu curso de conformidade. | Agente de resposta |

## Caminhos de aprendizado

| **Aviso** | **Ferramenta** |
|----|----|
| Ajude-me a encontrar um conjunto de cursos para aprimorar as habilidades no gerenciamento de projetos. | Gerar caminho de aprendizado |
| Salve este caminho de aprendizado. | Salvar caminho de aprendizado |
