# Conectar seu cliente de IA ao Adobe Learning Manager

O administrador de integração deve configurar o conector primeiro. Se não encontrar um conector do Adobe Learning Manager, entre em contato com o administrador. **O cliente está disponível somente para a camada do Adobe Learning Manager Ultimate**.

Os administradores podem consultar [Adicionar o Adobe Learning Manager ao cliente de IA.](/help/migrated/administrators/feature-summary/add-alm-to-ai-client.md)

1. Abra o cliente de IA da sua organização, como Claude ou ChatGPT Enterprise.
2. Localize o conector do Adobe Learning Manager na lista de conectores.
3. Selecione **Conectar**.
4. Faça logon com a identidade da sua empresa quando solicitado.
5. Faça uma pergunta sobre seu aprendizado. Para ideias, veja **exemplos de prompts para alunos**.

>[!NOTE]
>
>Você faz logon uma vez. Suas solicitações são executadas com suas próprias permissões, de modo que você veja apenas o que pode acessar no Adobe Learning Manager.

## Solução de problemas

**Não é possível localizar o conector**

Peça ao administrador para habilitar o conector para você.

**O cliente de IA não se lembra da sua pergunta anterior**

Cada solicitação é tratada como nova. A continuação de uma conversa depende do seu cliente de IA. Repita os detalhes na próxima pergunta.

**O cliente AI não chama o conector do Adobe Learning Manager**

Nomeie o que deseja em sua pergunta, como suas inscrições ou um tópico do curso.
