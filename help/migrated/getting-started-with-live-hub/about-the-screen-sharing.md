# Sobre o compartilhamento de tela

O compartilhamento de tela permite que os professores compartilhem conteúdo de seu dispositivo com os participantes em tempo real. Use o compartilhamento de tela para apresentar aplicativos, realizar apresentações, demonstrar fluxos de trabalho e orientar os alunos durante as tarefas. Os alunos também podem compartilhar suas telas quando um professor ativa o compartilhamento de tela.

Além de compartilhar uma tela, você pode exibir dois conteúdos lado a lado na Visualização dividida, usar um quadro de avisos junto com o conteúdo compartilhado e fazer anotações diretamente na tela para destacar as informações principais sem interromper a apresentação.

## Principais benefícios

* **Presente em tempo real**: compartilhe aplicativos, apresentações e fluxos de trabalho diretamente do dispositivo para que os alunos acompanhem enquanto ele acontece.

* **Mostrar mais de uma vez**: exibir até dois conteúdos lado a lado no Modo de Exibição Dividido, como um compartilhamento de tela e um quadro de comunicações, sem alternar para frente e para trás.

* **Explicar visualmente**: faça anotações diretamente no conteúdo compartilhado para destacar pontos principais, esclarecer conceitos e orientar a atenção dos alunos.

* **Combinar ferramentas**: execute um quadro de comunicações ao lado de uma tela compartilhada para adicionar explicações e observações conforme você apresenta.

* **Incentivar a participação**: permita que os alunos compartilhem suas próprias telas para apresentar seu trabalho ou apoiar discussões, enquanto os professores mantêm controle total da sessão.
