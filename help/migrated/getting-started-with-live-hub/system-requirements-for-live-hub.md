# Requisitos do sistema

Use os seguintes requisitos de sistema para configurar e executar sessões do Live Hub no Adobe Learning Manager. O Live Hub usa os mesmos requisitos de navegador, sistema operacional e hardware do ambiente da Sala de aula virtual em que é executado.

O Live Hub está disponível nas sessões de Sala de Aula Virtual e não requer uma instalação de cliente separada.

| Categoria | Requisitos |
|---|---|
| **Navegadores de desktop** | Versões mais recentes do Google Chrome, Mozilla Firefox, Microsoft Edge e Safari |
| **Navegadores para dispositivos móveis** | Chrome Mobile, Safari Mobile e Samsung Internet |
| **Sistemas operacionais** | Windows 10 ou posterior, macOS 15 ou posterior |
| **Resoluções de tela** | 1920 × 1080, 1366 × 768, 768 × 1024 (comprimido) e 375 × 667 (móvel) |
| **Hardware do Windows** | Mínimo de 8 GB de RAM, processador de 8 núcleos, Intel® Core™ i5 ou superior |
| **Hardware da Mac** | Mínimo de 16 GB de RAM, processador de 4 núcleos, 3,2 GHz ou superior |
| Rede **1** | Conexão de banda larga estável com pelo menos 5 Mbps recomendada para recursos de áudio ao vivo, vídeo e Live Hub com IA |

>[!NOTE]
>
>Os navegadores Linux, dispositivos Chromebook, Firefox Mobile, Opera (desktop e mobile), Internet Explorer 11 e versões mais antigas do navegador não são compatíveis.
