# Usar o painel Participantes como aluno

Como aluno, o painel Participantes permite ver quem mais está em uma sessão do Live Hub e interagir com eles com base nas permissões habilitadas pelo professor. Você pode exibir outros participantes, verificar os detalhes de um participante e enviar mensagens privadas quando essas opções estiverem disponíveis. Este guia explica como abrir o painel Participantes e interagir com outros participantes como aluno.

## Acessar o painel Participantes

Você pode usar o painel Participantes para exibir outros participantes na sessão e interagir com eles com base nas permissões habilitadas pelo professor.

Para abrir o painel, selecione ![abrir-painel-participantes](./assets/open-attendees.svg) na barra de controle. O painel lista todos na sessão para que você possa ver quem está presente.

## Interagir com outros participantes

No painel **Participantes**, você pode interagir com os participantes com base nas permissões habilitadas pelo professor.

Para acessar essas ações, selecione o ícone de **Mais opções ()** ao lado do nome de um participante no painel.

![Exibir Menu de Opções de Participante](assets/view-attendee-options-menu.png)
*Selecione o menu Mais opções para exibir os detalhes do aluno e enviá-los por mensagem privada.*

As seguintes ações estão disponíveis para o aluno:

| **Ação** | **Descrição** |
|----|----|
| **Enviar uma mensagem privada** | Abre o chat privado com o participante. |
| **Exibir perfil** | Mostrar as informações de perfil do aluno. |
