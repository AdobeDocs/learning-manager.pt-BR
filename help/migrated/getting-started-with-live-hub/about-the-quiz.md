# Sobre o quiz

O recurso Quiz em um Hub do Live permite que os professores criem e conduzam questionários para avaliar a compreensão do aluno durante uma sessão ao vivo. Você pode criar questionários antes ou durante a sessão, iniciá-los para coletar respostas em tempo real e monitorar os resultados à medida que os alunos respondem no painel da sessão.

>[!NOTE]
>
> Os questionários em uma sessão do Live Hub são diferentes daqueles criados na **ferramenta Criação de questionário** no Adobe Learning Manager.

## Principais benefícios

O recurso Quiz oferece os seguintes benefícios:

* **Avaliar os resultados do aprendizado**: avalie quão bem os alunos entenderam e mantiveram os principais conceitos após a instrução.

* **Realizar avaliações estruturadas**: crie questionários com várias perguntas para avaliar os alunos em um tópico ou módulo, além das verificações com uma única pergunta.

* **Acompanhar o desempenho individual**: os resultados do quiz ao vivo ajudam os professores a entender rapidamente como todo o grupo está se saindo e identificar áreas que podem precisar de mais esclarecimentos.

* **Melhorar o engajamento**: incentivar a participação ativa por meio de avaliações interativas.
