# Função de autores na sessão do Live Hub

Como autor no Adobe Learning Manager, você cria e gerencia cursos de sala de aula virtual que usam o Live Hub para fornecer treinamento ao vivo liderado por instrutor. Configure o curso, configure a sessão, atribua professores e publique-o para que a sessão esteja pronta para ser executada.

Este artigo descreve o que um autor faz ao trabalhar com o Live Hub.

## O que os autores podem fazer

Como autor, você é responsável pelas seguintes tarefas ao criar um curso do Live Hub.

### Criar cursos do Live Hub

Os autores podem criar cursos do Live Hub durante o fluxo de trabalho de criação do curso. Você pode:

* Adicione um módulo de sala de aula virtual ao curso.
* Escolha Live Hub como as Ferramentas de treinamento virtual do Live.
* Defina detalhes da sessão como título, descrição e duração.

### Configurar detalhes da sessão

Os autores podem definir como a sessão do Live Hub será conduzida. Você pode:

* Definir data, hora e fuso horário
* Configurar duração da sessão

### Use o Localizador de professores para atribuir professores

Use o Localizador de professores para localizar e atribuir professores com base no tipo de curso. Você pode:

* Receba recomendações de instrutor viabilizadas por IA com base nos requisitos, habilidades e disponibilidade do curso.
* Selecione um ou mais professores qualificados para a sessão.
* Acelere a configuração do curso com recomendações inteligentes e atribuição simplificada de instrutor.

### Publish e gerenciar cursos

Depois de configurados, os autores podem finalizar e gerenciar a entrega do curso. Você pode:

* Publish o curso para alunos
* Atualizar detalhes da sessão, se necessário
* Gerenciar a estrutura e os módulos do curso

Exiba [Criar uma sessão do Live Hub](./create-a-live-hub-session.md) para obter mais informações.
