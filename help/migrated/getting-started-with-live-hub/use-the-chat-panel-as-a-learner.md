# Usar o painel Bate-papo como aluno

Use o painel Bate-papo para participar de conversas durante uma sessão do Live Hub. Você pode enviar mensagens para todos os participantes, fazer perguntas e gerenciar suas mensagens de bate-papo. Se o seu professor ativou as mensagens privadas, você também pode conversar diretamente com outros participantes. Este artigo descreve os recursos de bate-papo disponíveis para os alunos.

## Acessar o painel de Bate-papo

Como aluno, você pode usar o painel Bate-papo para participar de discussões, fazer perguntas e se conectar com outras pessoas durante uma sessão.

Siga estas etapas para acessar o painel Chat:

1. Ingresse na sessão do Live Hub.

1. Selecione ![open-chat-panel](./assets/open-chat.svg) na barra de controle. O painel de Chat é aberto com a guia **Todos** por padrão, permitindo que você ingresse ou siga a conversa em andamento.

1. Selecione uma das seguintes guias:

   1. Todos

   1. Privado

   ![Guias do Painel de Chat](assets/chat-panel-tabs.png)
   *Painel de chat mostrando a guia Todos e Particular para comunicação.*

1. Digite sua mensagem e selecione **Enviar**.

## Personalizar o painel de Bate-papo

Você pode personalizar o painel Bate-papo para gerenciar notificações e melhorar a legibilidade de mensagens durante uma sessão do Live Hub.

Para personalizar o painel de Bate-papo:

1. Abra o painel **Chat**.

1. Selecione **Mais opções ()** no canto superior direito do painel Chat.

1. Selecione uma das seguintes opções:

   1. **Desativar notificações**: desabilitar notificações de chat para a sessão atual.

   1. **Alterar o tamanho do texto**: aumente ou diminua o tamanho das mensagens de chat para facilitar a leitura.

   ![Configurações do Painel de Chat](assets/chat-panel-settings.png)
   *Configurações do painel de chat que mostram opções para desativar notificações e ajustar o tamanho do texto das mensagens de chat.*

## Gerenciar suas mensagens de chat

Você pode interagir com as mensagens para manter as conversas organizadas e atualizadas. Responder a mensagens, reagir com emojis, editar mensagens após o envio ou excluí-las quando não forem mais necessárias.

Para gerenciar uma mensagem no chat:

1. Passe o mouse sobre a mensagem para exibir as ações disponíveis.

1. Selecione a ação necessária.

| **Ação** | **Descrição** |
|----|----|
| **Reagir** | Adicione uma reação de emoji para confirmar ou responder a uma mensagem sem enviar uma nova mensagem de chat. |
| **Responder** | Responder a uma mensagem específica. A resposta inclui uma referência à mensagem original para melhor contexto. |
| **Editar** | Atualizar uma mensagem após enviá-la. A mensagem editada substitui a mensagem original no chat. |
| **Excluir** | Remover sua mensagem do chat. Um rótulo “Mensagem excluída” aparece para manter o fluxo da conversa. |

## Enviar mensagens privadas

A guia **Particular** permite que você se comunique diretamente com outros participantes durante uma sessão sem compartilhar mensagens no chat público.

Para iniciar uma conversa privada:

1. Selecione a guia **Particular**.

1. Selecione um participante da lista.

   ![Guia de Chat Particular](assets/private-chat-tab.png)
   *A guia Particular mostra uma conversa individual entre um aluno e outro participante.*

1. Digite sua mensagem e selecione **Enviar**.

Uma conversa privada é aberta com o participante selecionado. As mensagens são visíveis apenas para você e para esse participante.

>[!NOTE]
>
> A disponibilidade do chat privado depende das configurações da sessão. Se o professor desabilitar o chat privado, você não poderá iniciar ou participar de conversas privadas.
